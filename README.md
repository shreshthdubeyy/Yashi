## ⚡ 1-Click Deployment to Vercel (Instant & Free)

This repository is optimized for **Zero-Config Vercel Static Hosting**:

1. **Push to GitHub**:
   ```bash
   git remote add origin https://github.com/<your-username>/<repo-name>.git
   git push -u origin main
   ```

2. **Deploy on Vercel**:
   - Go to [vercel.com/new](https://vercel.com/new).
   - Select your GitHub repository (`nov23-yashi`).
   - Leave Framework Preset as **Other** (it automatically detects the static site).
   - Click **Deploy**!
   - In 5 seconds, your live link is ready to share with Yashi:  
     `https://<your-project-name>.vercel.app`

## ✨ Features

- **🎀 Minimal & Girly Scrapbook Aesthetic**: Warm cream, soft blush, and dusty rose tones with delicate washi-tape polaroids and handwritten margin notes (*Playfair Display* + *Plus Jakarta Sans* + *Caveat*).
- **🎶 Automatic Background Song**: Integrated [`song.mp3`](./song.mp3) with an aesthetic spinning vinyl disc player and seamless autoplay on first touch/interaction.
- **🖥️ Fullscreen Mode by Default**: Opens edge-to-edge automatically or via in-app toggle (`⛶` button / `F11`).
- **📸 High-Resolution Photo Gallery**: 8 curated authentic moments with an interactive fullscreen Lightbox viewer (keyboard navigation `←` `→` `Esc` supported).
- **⭐ Secret Birthday Wishing Well**:
  - When Yashi types her wish and taps **"Send ✨"**, she sees celebratory rose petal confetti and a confirmation note.
  - In the background, Google Apps Script silently delivers her exact wish straight to your **Gmail inbox** (`shreshthdubeyy@gmail.com`) with zero popups or alerts.
  - **1-Key Reveal Shortcut**: Press **`W`** on your keyboard or tap the **`Y`** monogram in the top-left header to view her saved wish anytime.
